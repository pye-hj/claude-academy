# answer-placement コンポーネント

選択式（4択）問題の**正答位置の決め方**の規約です。

**使い方**：選択肢を1問も書き始める前にこのファイルを`Read`で読み込み、下記の手順で正答位置を確定してから作問してください。

## 手順

### 1. 作問前に正答位置列を生成する

選択式の問題数`n`を確定し、**選択肢を書く前に**次を実行します（末尾の引数が`n`）。

```sh
python3 -c "
import random, sys
n = int(sys.argv[1])
while True:
    s = [random.randint(1, 4) for _ in range(n)]
    if any(a == b for a, b in zip(s, s[1:])):
        continue                      # 隣接する問で同じ位置にしない
    if len(set(s)) < min(n, 4):
        continue                      # 使える位置はすべて1回以上使う
    break
print(' '.join('ABCD'[i - 1] for i in s))
" 5
```

出力例：

```
C A D B A
```

### 2. 出力をそのまま配置に使う

上の例なら、問1の正答はC、問2はA、問3はD、問4はB、問5はA。これで固定します。

### 3. 正答を先に置き、残りを誤答で埋める

各問について、**まず正答の文面を書いて指定位置に置き**、空いた位置を誤答で埋めます。4つ書いてから並べ替えるのではありません。順序が逆になると、結局「書きやすい位置」に正答が寄ります。

### 4. 位置列を成果物に残さない

生成した位置列を、HTMLコメント・`data-*`属性・見出し・`<script>`内の変数名などに書き込まないでください。ページのソースから答えが読めてしまいます。

## Do / Don't

- Do: 講座・テストを生成するたびに1.を実行する。使い回さない。
- Do: JSのハンドラで正誤を持つ実装（`answer(..., true, ...)`など）では、`true`を渡す選択肢が1.で決めた位置と一致していることを確認する。
- Don't: 位置を自分の判断で決めない。「今回はBが自然だから」は禁止。
- Don't: スクリプトの出力を、読みやすさ・自然さ・難易度調整などを理由に並べ替えない。並べ替えた時点でこの規約は無効になる。
- Don't: 先に選択肢を4つ書いてから、あとで正答の位置を調整しない。
