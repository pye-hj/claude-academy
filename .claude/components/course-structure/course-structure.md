# course-structure コンポーネント

`syllabus.html`（`generate-syllabus`スキル）と`lecture.html`（`teach`スキル）の**構造規約**です。

**使い方**：シラバス／講座を生成する前にこのファイルを`Read`で読み込み、下記の規約を満たすHTMLを出力してください。

**この規約が縛るのは機械的な契約だけです。** 配色・レイアウト・コンポーネント設計・文体は講座ごとに自由に決めて構いません。ここに書かれていないことは制約されていません。

## なぜ規約が要るのか

`share-course`スキルは`bundle.py`で全講座を1枚の共有ページへバンドルします。その際、講座ごとの区画をShadow DOMに収めたうえで、リンクの張り替え・画像のdata URI化・インラインハンドラの名前空間化を行います。下記はその処理が成立するための前提です。

**前提を外しても手元のブラウザでは正常に見えます。** 共有ページを作るまで気づけないため、規約として先に固定します。各項目には理由を添えています。理由の側が変わらない限り、項目を省略しないでください。

## 共通

| 規約 | 理由 |
|---|---|
| 出力先は`artifacts/<テーマ名>/syllabus.html`と`artifacts/<テーマ名>/lecture-<n>/lecture.html` | 後続スキルがこのパスを前提に探索する |
| 講座ディレクトリ名は`lecture-<数字>`ちょうど（`lecture-01`のようなゼロ埋めをしない） | `collect_sections`が`lecture-(\d+)`で完全一致させる。外れた講座は無言で同梱対象から落ちる |
| `<body>`を持つ完結したHTMLとして出力する | `extract_body`が`<body>`の中身を区画本文として取り出す |

## syllabus.html

| 規約 | 理由 |
|---|---|
| `<title>`は`<コース名> シラバス`（末尾を「シラバス」にする） | `course_name`が接尾辞を落として共有ページのコース名にする |
| 各回のブロックに`id="lecture-<n>"`を付ける | `teach`が講座生成後にリンクを追記する際の足場。これが無いと追記先を推測することになる |
| 各回のブロック内に`<a href="lecture-<n>/lecture.html">`をちょうど1つ置く | `rewrite_links`がこの形のhrefだけを共有ページ内の区画遷移に変換する。別の書き方だと死んだリンクになる |
| 難易度は`class="badge beginner"` / `standard` / `advanced`で示す | シラバスと講座で表記を揃えるため |

配色・カードのレイアウト・見出しの付け方は自由です。

## lecture.html

| 規約 | 理由 |
|---|---|
| `<title>`は`講座NN — <見出し>`（`第N回 — `／`Lecture N — `も可） | `lecture_label`が接頭辞を落として目次ラベルにする。外れると目次に番号が二重に出る |
| 講座間リンクは`../lecture-<n>/lecture.html`、シラバスへは`../syllabus.html`ちょうど | 同上、`rewrite_links`が変換対象を厳密一致で判定する |
| 理解度チェックを1つ以上置く。**実装形式は自由**（`<details>`でもJSでもよい） | 講座の締めを共通の体験にするため。形式は縛らない |
| JSを使う場合、ハンドラから呼ぶ関数は`<script>`の**トップレベル**で定義する（`function f(){}`または`const f = () => {}`）。IIFEや`DOMContentLoaded`の中に隠さない | `namespace_handlers`がトップレベル定義しか拾えない。隠すと**共有ページで理解度チェックが無反応になる** |
| 外部CDNスクリプト（`<script src="https://...">`）を使わない | 公開ページのCSPで遮断されるため、`pop_inline_scripts`が除外する |
| 画像は講座ディレクトリからの相対パスで参照する（`images/foo.png`など） | `inline_assets`がdata URIへ埋め込む。外部URLの直リンクは公開ページで読み込めない |
| 本文に`</template>`という文字列を含めない | 区画テンプレートが途中で閉じ、描画が崩れる |

配色・レイアウト・図解・コード例の見せ方は自由です。

## Do / Don't

- Do: 講座ごとにデザインを変えてよい。この規約は見た目を縛らない。
- Do: 迷ったら既存の`artifacts/<テーマ名>/`配下の成果物を参考にする。
- Don't: 講座ディレクトリ名や`<title>`の形式を独自に変えない。同梱から静かに漏れる。
- Don't: 理解度チェックのJSを`DOMContentLoaded`やIIFEで包まない。
- Don't: CDNからのスクリプト読み込みや外部URLの画像参照を入れない。
